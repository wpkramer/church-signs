# Privacy Policy for ChurchSigns

**Last updated:** August 25, 2026

ChurchSigns (“the app”) is a free, open-source Windows application designed to help churches create and print signs and labels.

## What data does the app handle?

The app can process data that you provide, such as names and other information from spreadsheets (for example, teacher names for classroom signs).

## How is this data handled?

- Data is held **only in memory** for the current print job.
- When you close the job or close the application, the data is discarded.
- The app does **not** save this data to disk.
- The app does **not** send this data to any server or third party.
- The app does **not** create user accounts or require sign-in.

## What we do not collect

ChurchSigns does not collect, store, or transmit:

- Personal information
- Usage analytics
- Device identifiers
- Crash reports (unless you later choose to enable optional diagnostic features)

## Internet access

The current version of ChurchSigns does not require an internet connection to function. Future versions may optionally check for updates; if that happens, this policy will be updated.

## Children’s data

The app is intended for use by church staff and volunteers. It is not designed to store or manage information about children. Any names you choose to process remain only in memory for the duration of the print job.

## Changes to this policy

If the way ChurchSigns handles data changes, this privacy policy will be updated and the “Last updated” date will change.
